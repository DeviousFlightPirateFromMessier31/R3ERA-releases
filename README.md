# R3ERA-releases
Explore your results from Raceroom race files. The app runs a bottle micro web-framework server and builds a SQLite database from your race results files that Raceroom saves after every race or replay. You then connect to the server with any web browser to use the app.

## Usage
1. Extract anywhere.
2. Run.
3. Start your browser at localhost:8080
4. Upload race files. Find r3e-data.json and the path to your race results files. First uploading of race files can take a few minutes depending on how many files you have. For me, about 8 mins for ~3000 files.
5. Find your raceroom ID(s) and save them.
6. Explore.
