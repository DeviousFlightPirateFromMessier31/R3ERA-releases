# R3ERA-releases
Explore your results from Raceroom race files.

1. Extract anywhere.
2. Run.
3. Start your browser at localhost:8080
4. Upload race files. Find r3e-data.json and the path to your race results files. Uploading can take a few minutes depending on how many files you have.
5. Find your raceroom ID(s) and save them.
6. Explore.
